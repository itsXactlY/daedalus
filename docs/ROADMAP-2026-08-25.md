on-mission for **days, weeks, months**. Nothing "replaces" the main model;
the memory plane routes state OUT (what persists) and IN (what re-enters the
head each turn). ALICE (local Qwen router seat, `:8801`) exists to make that
routing intelligent — not to answer queries better than the main model.
