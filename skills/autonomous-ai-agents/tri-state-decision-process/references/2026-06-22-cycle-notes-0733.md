### 3. 826172 — inside 2h dedup window but not a duplicate

826172 was created 05:54Z, this cycle 07:33Z = 1h39m gap — technically **inside the 2h dedup window**. But the 06:07Z cycle's decision (826188) only ranked 826173 (Nature 98-qubit), NOT 826172 (IonQ FTQC). The 06:07Z decision's content explicitly listed 826172 as a sibling but didn't write it as a separate rank.

**DEDUP handling**: A discovery is "already decided" if a `decision:rank-*` exists whose content references it as the primary Discovery Memory ID. 826172 was referenced as a SIBLING in 826188's content, not as the primary discovery. So 826172 was eligible for ranking.

**Future cycle guidance**: Cluster siblings listed in a parent decision's "Sibling cluster" or "Siblings not separately ranked" section are eligible for re-ranking in subsequent cycles, but only if they provide a **distinct artifact** (commercial vs academic, supply vs demand, mechanism vs concept, etc.). The 826172 case qualifies: 826188 is the academic Nature paper, 826172 is the commercial IonQ technical report. Pure duplicate siblings (same artifact type, same axis) should still be skipped.
