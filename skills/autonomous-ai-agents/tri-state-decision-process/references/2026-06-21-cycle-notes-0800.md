## Three-Front Synthesis Pattern (NEW — worth standardising)

This cycle picked three discoveries that, on the surface, looked unrelated:
- 825471 Anthropic "silent sabotage" (vendor-offensive countermeasure against Fable)
- 825468 US State Dept diplomatic cable (US diplomatic action vs. Chinese AI vendors)
- 825300 North Korean 140+ npm attack (state-actor supply chain attack on agent tooling)

Each touched a different cluster (Anthropic-fable, US-China policy, agent-supply-chain). After scoring, the cycle synthesis step explicitly framed them as **three distinct escalation channels of US-China AI competition** — model-vendor offensive (#1), US diplomatic (#2), state-actor supply chain (#3). That synthesis became the CYCLE CONTEXT block in all three `mazemaker_remember` calls AND was surfaced in the final report's "Three-Front US-China AI Competition Pattern" section.

**Pattern (PATCH AS A STEP):** After scoring the candidate pool and before writing the top 3, run a synthesis pass: try to frame the top candidates as N distinct facets of a single underlying theme (e.g., "three channels of X", "three layers of Y stack", "three time-bands of Z trend"). If a coherent synthesis exists, name it in the CYCLE CONTEXT block of every rank — it makes the ACT phase's downstream work easier because the 3 decisions can be processed as a unit rather than 3 disconnected items.

**When synthesis FAILS:** If the top 3 candidates resist unification (e.g., one is a software-engineering finding, one is a security CVE, one is a market signal), do NOT force a synthesis. Just list the 3 ranks as 3 distinct angles. The 01:00 / 03:30 cycles used the "evaluation-methodology / model-vendor / agent-orchestration" diversity framing as a fallback when no unifying theme existed.

## Distinct-Cluster Selection Heuristic (NEW)

This cycle's pool was 44 unranked discoveries. The Anthropic-Fable-Mythos cluster had 8+ recent findings (825471, 825468, 825062, 825066, 825061, 825159, 825307, 825415, etc.). The naive top-3-by-score would have picked 3 from this single cluster.

**Heuristic (PATCH AS A PITFALL):** When picking the top 3, prefer ONE per distinct cluster. Rationale: 3 ranks from the same cluster produce redundant decisions that the ACT phase can't act on in parallel. The Anthropic cluster scores high on connectedness (0.5-0.7) and recency (often <30 min old) but the underlying signal is one event sequence — 3 ranks don't add information.

**When to break the rule:** If one cluster has a critical-priority event AND no other cluster has anything novel that cycle, fill the remaining 2 ranks with cluster extensions (using the `decision:rank-*<rank-N>` numbering pattern from prior cycles). The 825414-via-825447 cycle demonstrated this — 3 NICE_TO_KNOW ranks all from the claude-code reverse-engineering cluster.

## High-Similarity-to-Existing Discovery (gotcha)

825468 (Chinese AI distillation State Dept escalation) had max similarity 0.7776 to `fact:open-source-frontier-2026 825458` — meaning the underlying Anthropic accusation was already in the corpus. The novelty score was only 0.222. By the standard formula, this should have been a borderline-rank candidate.

**Why it was still ranked:** The diplomatic escalation (Apr 30 State Department cable) was genuinely new content not in any prior decision or fact. The discovery elevated an existing fact into a stand-alone finding with a fresh decision-action surface (compliance note in hermes-agent for DeepSeek/Moonshot/MiniMax outputs).

**Pattern (PATCH AS A PITFALL):** A discovery with high similarity (>0.7) to an existing fact:* or decision:* is NOT automatically noise. Check whether the discovery adds a NEW ANGLE on the existing content (e.g., escalation to a new actor, new date, new channel, new consequence). If yes, rank it; if no, skip. The novelty score alone is insufficient — pair it with a content review of the top-3-similarity matches.
