## Score formula recap (verified this cycle)

```
score = connectedness + novelty + recency_weight + priority_boost
```

- connectedness = fraction of top-10 `mazemaker_recall(topic)` results that are fact:*/decision:*
- novelty = 1 - max similarity to closest non-self memory (excluding self + bias-noise)
- recency_weight = freshness score (1.0 for ≤15min old, 0.95 for ~1h, 0.85 for ~5h, 0.65 for ~24h)
- priority_boost = +0.10 for IMPORTANT/CRITICAL signals (primary-source event, regulatory inflection, blocking issue, top-tier clinical venue + Phase 2b+ trial, etc.)
