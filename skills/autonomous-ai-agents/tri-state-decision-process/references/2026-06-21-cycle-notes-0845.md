## Single-Tick Orthogonal-Academic-Layers Pattern (NEW — refinement of distinct-cluster heuristic)

The 08:00 cycle documented "distinct-cluster selection heuristic" — prefer ONE per distinct cluster. The 08:45 cycle refined this for single-tick scenarios: when a single pulse-wurm tick produces 7+ discoveries spanning multiple academic domains, the top 3 should pick ACROSS the academic layers, not within one layer.

**Why:** A single tick often surfaces a coherent research-cluster (e.g., a conference venue + student-term-project + bootcamp-tutorials all in the same domain). Picking 3 from the same academic layer within the tick produces redundant decisions. Picking 1 from each layer produces cross-cutting decisions that ACT can act on in parallel.
