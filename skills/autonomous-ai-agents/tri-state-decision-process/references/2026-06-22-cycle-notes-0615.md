## New pitfalls/techniques discovered

### 1. Earlier-cycle rank-of-companion dedup (NEW)
**Signal**: The 2h dedup window catches re-rankings within 2h but misses parent/companion relationships across 3h+ gaps.
**Concrete example this cycle**: 
- 826077 (Anthropic S-1) → ranked as 826095 in the 02:00Z cycle (4h+ old) — excluded by 2h dedup correctly
- 826070 (Anthropic IPO + $36B debt + autonomous cyberattack, body_length=0 low-confidence) → IS a companion to 826077, but only 1h21m old so NOT in 2h dedup window
- The fix: read the parent decision's content (826095) and find explicit "Companion <id> is also not yet ranked" notes. Those companions ARE the new candidates.

**Solution**: read parent decision content via `mazemaker_get(memory_id=N)` and grep for `Companion <id>` patterns. If found, the companion is a candidate. Apply small novelty boost (+0.05-0.10) because the prior decision's deferral IS a hand-off to the next cycle.

### 2. Large result file parsing via execute_code (NEW)
**Signal**: `mazemaker_recall` and `mazemaker_browse` can return >100KB for broad queries.
**Concrete example this cycle**:
- `mazemaker_browse(label_prefix='discovery:', limit=100)` returned 309KB (saved to /tmp/hermes-results/call_019eedf925657f308fb053aa.txt)
- `mazemaker_recall(query='discovery:pulse-tick-*', limit=50)` returned 504KB (saved to /tmp/hermes-results/call_019eedf894f47250b2eafce8.txt)

### 4. body_length=0 low-confidence flag handling (NEW)
**Signal**: Pulse discoveries can have `body_length=0` meaning only the title was retrievable (URL body fetch failed).
**Concrete example this cycle**: 826070 had body_length=0 → marked as low-confidence flag.
**Solution**: in the decision's DEDUP NOTE, explicitly call out the low-confidence flag. Do NOT take any code-fix action on body_length=0 discoveries without independent verification.
