### Connectedness scoring for under-represented fresh-direction domains (NEW — refinement)

The connectedness formula (`count of fact:*/decision:* in top-10 of mazemaker_recall`) can be LOW (<0.40) for fresh-direction picks from under-represented domains, even when the cluster is thematically related to existing themes. This is because:
- The fresh-direction domain has few existing fact:*/decision:* memories (low base density)
- The thematically-related memories in the corpus use different vocabulary (e.g., Fable 5 export controls ≠ Huawei chairman export controls)
- The semantic search ranks by query-word overlap, not by cluster-membership

**Verified 2026-06-22 13:30Z cycle:**
- 826357 (Chevron-Microsoft) — connectedness 0.60 (fact:hyperscaler-2-1-trillion-backlog + fact:microsoft-chevron-2_7gw + 2 freshdir URL duplicates) — moderate, reflecting the existing AI-data-center-bifurcation cluster
- 826353 (Huawei chairman) — connectedness 0.30 (826353 self + 826354 sibling + fact:fable5-chinese-group-access — only 1 topically-related) — LOW because the Huawei-SMIC cluster has no prior fact:*/decision:* memory
- 826215 (Boötes III neutrino DM) — connectedness 0.20 (826215 self + 826216 sibling) — VERY LOW because the dark-matter indirect-detection cluster has no prior memory

**Refined rule (NEW):** connectedness=0.20-0.40 is GENUINE for fresh-direction picks from under-represented domains. Do NOT inflate the connectedness to compensate for low topic-recall count. Instead, apply the freshness + novelty axes as the primary score drivers, with connectedness as a secondary tie-breaker. The total-score formula remains connectedness + novelty + recency, but the weights naturally distribute differently for fresh-direction picks.

**Diagnostic shortcut (NEW):** if the topic-recall top-3 are mostly the discovery itself + same-tick siblings + tangentially-related fact:*/decision:* (not topically-related), the connectedness is genuine. If the top-3 are topically-related (same cluster, same axis, same author), the connectedness is inflated and should be discounted (per the existing "Connectedness-score inflation from tangentially-related decisions" pitfall).
