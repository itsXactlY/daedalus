## Critical learnings this cycle

### Pool-collection: prefer `browse(label_prefix='discovery:')` over `recall(query='discovery:*')` (NEW)

The first attempt at pool collection used `mazemaker_recall(query='discovery:pulse-tick-*', limit=50)` per the canonical recipe. Result: 50 results returned, but only **3 were actual `discovery:` labels** (826081, 821359, 808739) — the remaining 47 were `decision:rank-*` entries that mentioned the discovery IDs in their CYCLE CONTEXT or PAIR sections. The recall semantic-search engine ranks decision:rank-* entries higher than the actual discovery memories they reference, because the decisions' content embeds the discovery ID + topic, creating a high-cross-query similarity match.

The fallback that worked: `mazemaker_browse(label_prefix='discovery:', limit=30)` returns the 30 most-recently-created memories with `discovery:` label, ordered by `created_at` DESC. This is the canonical 30-discovery 24h window.

**Future cycle guidance**: For pool collection in DECIDE phase, **use `browse(label_prefix='discovery:')` first** (gets the actual 30 most-recent discoveries with timestamps for 24h filtering), then use `recall()` for connectedness scoring on individual topics. The recall-based pool collection is unreliable for getting the actual discovery set.

### Recall connectedness is corpus-density noise for unrelated-topic queries (REFINEMENT)

The ToM cluster's recall for "machine theory of mind" returned 4/10 fact:*/decision:* labels (825751 LEO-orbital-debris, 826061 NPC ML survey, 825808 Claude Code leak, 822515 SecureClaw) — but **none of these are about philosophy of mind / ToM**. The 4/10 connectivity is **corpus-density noise** (the pulse-wurm corpus is densely cross-referenced, so any recall query returns some decision:rank-* from unrelated topics), not topic-specific connectivity.

**Refinement to the existing connectedness formula**: The 0.4 connectedness for ToM overstates the topic-specific connectivity by ~0.3-0.4. The ACTUAL topic-specific connectivity for "philosophy of mind / ToM" in the corpus is 0.0 — no prior decisions cover this domain.

**Future cycle guidance**: When scoring connectedness, manually verify that the fact:*/decision:* labels in the top 10 are TOPIC-RELEVANT, not just corpus-density. A 0.4 connectedness with 4 unrelated decisions is functionally similar to 0.0 connectedness for the candidate's own topic. The score formula still works for priority ranking, but the ACT phase should not interpret a 0.4 connectedness as "this is well-connected to the existing graph" without manual topic-relevance verification.
