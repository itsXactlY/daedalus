### Three `discovery:pulse-wurm-*` label timestamp formats
The label prefix `discovery:pulse-wurm-*` has three timestamp shapes that the 24h filter must handle:
1. `discovery:pulse-wurm-YYYYMMDD_HHMM_tick` — e.g., `discovery:pulse-wurm-20260621_2017_tick` (full timestamp, sortable)
2. `discovery:pulse-wurm-YYYYMMDD_topicname` — e.g., `discovery:pulse-wurm-20260621_gascity-multi-agent-sdk` (date-only with topic slug)
3. `discovery:pulse-wurm-YYYYMMDD_tick-summary` — e.g., `discovery:pulse-wurm-20260620_tick-summary` (date-only with literal "tick-summary")

The strict regex `(\d{8})_(\d{4})` only catches format #1. Format #2 and #3 need `(\d{8})` alone, then compare `YYYYMMDD` against today's date or `today-1` for 24h window. **Filter recipe:** match `(\d{8})` and compute age in days; include if age ≤ 1 day.
