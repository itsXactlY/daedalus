## Patterns observed this cycle

### Honourable mention pattern (NEW — see SKILL.md)
826367 SpaceX-Cursor $60B all-stock acquisition scored 2.101 (just outside top 3) but is a CRITICAL macro event. The scoring formula lacks a priority term, so a corpus-anchored CRITICAL item can score below NICE_TO_KNOW items. The right output is: write the top 3 by score, log the just-outside-top-3 CRITICAL as an honourable mention. ACT phase reads the log and can elevate the honourable mention to its own action item.

### Parallel batch recall() file-path determinism issue (NEW)
Ran 15 `mcp__mazemaker__mazemaker_recall` calls in a single parallel batch. The persisted-output files in `/tmp/hermes-results/call_*.txt` were assigned non-deterministically; the agent could not know which file was which by filename alone. Had to re-parse files by their first result's `id` and `label` to recover the query-to-file mapping. Future cycles: limit parallel recall batches to 2-3 queries at a time.

### Pool-collection browse() vs recall() confirmation
The 13:45Z cycle confirmed (again) that `mazemaker_browse(label_prefix='discovery:', limit=50)` is the canonical pool-collection method, NOT `mazemaker_recall(query='discovery:*', limit=50)`. The recall returns mostly `decision:rank-*` (47/50) + only 3 actual `discovery:` memories; the browse returns 50 `discovery:` memories ordered by `created_at` DESC.

### Connectivity inflation (extension of 13:00Z pitfall)
All 15 recall queries returned 6-10/10 fact+decision in top-10, confirming the connectivity inflation pitfall from the 13:00Z cycle. Even fresh-direction picks from under-represented domains (climate, history) had 8/10 fact+decision counts because the recent decision cache is saturated. The score-formula connectedness component is increasingly noisy; future cycles should lean on topical-relevance ratio (top-3 topical match) as a secondary check.
