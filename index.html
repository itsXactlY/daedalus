Daedalus

An autonomous agent harness built to retrieve its history instead of hauling it.
Fork of Hermes Agent 0.8.0. Requires Python 3.14+.

This is not a drop-in upstream replacement. Daedalus was deliberately taught to stop carrying its own history — it only works with a Mazemaker backend. Run without Mazemaker and you get an amnesiac agent, worse than upstream by construction. See mazemaker.online for the backend.

Daedalus runs on any OpenAI-compatible endpoint: llama.cpp, Ollama, vLLM, Unsloth Studio, OpenRouter, Anthropic.
